# Event scenes v1

Generated for this project with OpenAI's built-in image-generation tool on 2026-09-26.

Runtime asset: `event-scenes-v1.webp`, 1536 × 1024, 3 columns × 3 rows, no gutters. PNG retained as source. CSS displays tiles without cutting the atlas into separate downloads. WebP is a format conversion, with no content edits.

Row-major order: summoning/library, food stall, singing cats, forest hot spring, basketball court, prop-film kaiju city, office, trinket shop, hidden archive.

The nine illustrations depict recurring event settings. They are not sixty unique illustrations or different images for every outcome. Each of the sixty events has separately authored dialogue and context in `run-events.js`. Selection keeps its scene, changes the reaction, and shows the actual rewards from the saved result.

Art direction: consistent schoolboy with messy black hair, navy-and-white school uniform and red backpack; warm gold lighting, petrol-blue shadows, pixel-art fantasy comedy; interactions instead of combat poses; no baked-in UI or words. Main subjects centered for responsive cropping.
